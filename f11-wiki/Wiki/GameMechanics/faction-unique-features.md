# Faction Unique Features

**Each faction has a unique feature, important to the final game mode when the protagonists join
up.** Features are **unlocked through gameplay** and themselves **unlock progress, like Metroid**.

**State:** concept · **Category:** progression

**Implemented by:** _(no feature notes yet)_

## How It Works

Two claims, and the second is the more interesting one:

1. Each faction contributes one distinctive capability.
2. Those capabilities converge — there is a **final game mode** in which the protagonists have
   joined up, and the features matter *there*, together.

Structurally this is Metroid-style gating stretched across ten games rather than one map: an
ability earned as one protagonist opens progress, and the endgame is the set of them combined.

**Three are named** (2026-08-08) — only the factions actually designed. The other seven are
deliberately left blank rather than invented; see [[faction-design-status]].

| Faction | Unique feature |
|---------|---------------|
| [[robots]] | **Repair and remote communication** — restoring broken machines, and reaching one's own bots at a distance. Already the mechanism behind [[the-first-signal]] and [[the-calling-of-ancient-allies]]. |
| [[institute-of-eight]] | **Timing** — the trained ability to read a rhythm and act on the beat ([[ninja-rhythm-platforming]]). |
| [[celestials]] | **Hero defence** — holding a position as a single unit that can be everywhere ([[celestials-hero-tower-defence]]). |
| the other seven | **not yet named** |

Note that the Robots' feature has *already* done cross-faction work twice, in two chapters, which
is the strongest evidence so far that the converging-features idea is sound. Three named features
is enough to test whether the final game mode works — which is worth doing before committing seven
more.

Still not established: whether a feature earned by one protagonist becomes usable by another
before the endgame, and what the final game mode actually is.

## Why It's Fun

Not yet stated by the author. Note the design promise it makes, though: it is the mechanical
version of the story's premise. The stories converge in fiction; the features converge in play.
