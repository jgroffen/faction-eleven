# 2026-08-24 — Round 30: a heal is a patch, and the witness ladder

## Details

New lore note a-heal-is-a-patch. The fixbots' heal skill repairs the code of the entity being fixed, which is why the same ability mends a robot and heals the Ninja - to something working at that level a person and a machine are the same kind of object. Of the ten fictional excuses for healing in death-and-return this is the only one literally true about the game the player is holding. Side effect: fixbots see retcons land, where every other character absorbs the rewrite and behaves as though the new continuity was always the case. This corrects the compiled claim in continuity-glitches that protagonists mostly cannot see glitches and that the Gargoyle is the exception. There are now several witnesses by two separate mechanisms - code sight for the fixbots, and dormancy-preserved memory for Gargoyle and Odie - and one of them, Autofix, leads chapter one. Witness ladder recorded, in which seeing, understanding and self-trust are three different things and no character has all three: Autofix and Odie see without understanding, having barely been running; Mifix sees and has a framework but knows his own code is degraded from running too long, and no-machine-repairs-itself means he can never audit himself; Odie is the control case with code sight and an uncorrupted memory but no framework; the liches see, understand and explain. The liches present genuine knowledge of the realms and of the infrastructure the games run on as ancient eldritch lore - a costume rather than a lie, which makes them the game's most dangerous exposition. Planned gag recorded as intent: the Glitch Lich, liches cause glitches. Design consequence: in-fiction witnesses are a deniability shield, so strong-tier glitches are safest around fixbots and liches and more expensive elsewhere - now a placement rule in continuity-glitches and story-continuity-timeline. The handover's next step moves from the Gargoyle to robots-incremental-exploration, where the detection instrument already is.
